## 결정 대기 중인 것

### ① 추격이 성립하는가 (기획서 §4.3) — S3 착수 시 필요
술래와 도망자가 같은 속도로 한 칸씩 움직이면 **거리가 영원히 좁혀지지 않아 잡을 수 없다.**

- **A. 쿨다운 차등** — 도망자 400ms / 술래 320ms → **v1 권고**
- **B. 벽 텔레포트** — 술래가 자기가 설치한 벽 사이를 순간이동. 설치 단계가 "내가 튀어나올 구멍" 설계로 바뀐다. 가장 흥미롭지만 밸런싱 난이도 높음

권고 순서: **A로 시작해 B를 실험.**

### ② 보류 항목
| 항목 | 사유 | 재개 조건 |
|---|---|---|
| 워커 추론 분리 | 오류 없이 ready 는 오는데 프레임이 안 흐름. 원인 미특정 | 씬이 무거워져 히칭이 눈에 걸릴 때. 구현계획 S2 「재검토 조건」 |

## ⚠️ 인수인계 시 알아둘 것

**나(Claude)는 이 프로젝트의 화면을 한 번도 직접 본 적이 없다.** 문법·CDN 응답·서버 응답만 검증했다.
따라서 아래 값들은 **계산 또는 추정치**이며, 눈으로 보고 고쳐야 한다.

- 조명 세기 34 / 톤매핑 노출 1.05 / 환경광 0.03
- 안개 밀도 0.105 (4칸에서 76% 가림 — 계산으로 도출)
- 그것의 캐릭터 비율 (머리 154×172, 팔 9×106, 다리 10×114)
- One Euro 기본값 `mincutoff 1.0` / `beta 0.007`
- 게이트 임계값 (발동 0.24 / 재장전 0.1 등)
- **소리 전 항목** — 드론/심장박동/속삭임/방 소리/그것의 숨/스팅어 모두 실시간 합성이고 나는 들어본 적이 없다.
  마스터 앞 리미터(threshold -8dB, ratio 12)를 믿고 기본값을 세게 잡아뒀다 — 시끄러우면 `마스터`부터 내린다.
  오른쪽 아래 `소리` 패널에서 조절한 뒤 `튜닝값 콘솔 출력`에 함께 찍히는 `sound` 값을 기록한다.

**이미 실측으로 확정된 것** (바꾸지 말 것):
- 회전 부호 — 코드에서 뒤집어 확정 (왼쪽 = 좌회전). `회전 방향 반전` 체크박스는 건드리지 않는다
- 추론 스레드 = 메인, 추론 20fps, 블렌드셰이프 끔, 해상도 배율 1.0
